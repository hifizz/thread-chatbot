# Beta 开放清单

本清单初始全部 not_run。方案合并、OpenSpec 校验通过不等于产品验收通过。每项需填候选 commit、环境、时间、负责人、证据路径和结果；公开仓库不得包含用户原文、secret 或私有测试凭据。

## 放量与回退

建议首批 10 人，再根据任务完成/错误/成本/支持负担评估 30/100 人；数字是试行规模而非容量保证。每次扩大都保存 decision，关键策略/模型/价格/部署改变需重新跑受影响门禁。

失败时暂停新邀请或新付费工作，保持已有任务/账务事实可恢复，使用已核验 provider/镜像回滚。不要通过删除账目、取消权限检查、回退匿名无额度约束来假装恢复。
