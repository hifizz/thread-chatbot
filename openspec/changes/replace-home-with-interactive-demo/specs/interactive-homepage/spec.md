# interactive-homepage

## ADDED Requirements

### Requirement: 场景化三列交互演示
系统 SHALL 在首页提供五类场景标签共用的三列演示窗口，覆盖写 PRD、技术方案、营销方案、深度调研、专题学习（自学 AI / 看懂上市公司）共六套预设剧本。演示 MUST 为纯前端静态内容，不得调用真实模型、创建真实会话或写入用户数据。默认场景为「写 PRD」。

#### Scenario: 访客切换场景
- **WHEN** 访客点击任一场景标签或学习子标签
- **THEN** 演示重置为该场景起点，不残留上一场景的消息、引用或计时器

#### Scenario: 演示播放与阅读
- **WHEN** 演示进入视口（≥35%）且用户未设置减少动态效果
- **THEN** 剧本自动播放；用户可暂停、恢复、重播，或点击章节直接跳转，跳转后画面为该章节的完整一致状态

### Requirement: 来源短语与分支导航
系统 SHALL 在演示中把可分叉的短语渲染为可点击锚点（高亮 + 脚注编号），点击后停掉自动播放并展开对应分支列的完整状态。分支列 MUST 展示来源横幅（父级面包屑 + 引用原文）与继承上文提示。

#### Scenario: 访客点击来源短语
- **WHEN** 访客点击主线回答中带脚注的短语
- **THEN** 对应分支列展开，来源短语与父消息对应可见，自动播放暂停

### Requirement: @Artifact 结论回流
技术方案剧本 MUST 完整演示：子分支讨论 → 形成带标题的 Artifact → 回到主线输入 `@` → 出现可选择列表 → 选择结论 → 显示引用胶囊 → 发送 → 主线基于该结论继续回答。`@` 列表 MUST 同时支持鼠标与键盘（↑/↓/Enter/Escape），Escape 关闭后焦点回到输入框。

#### Scenario: 键盘选择 Artifact
- **WHEN** 弹层打开时访客按方向键移动高亮并按 Enter
- **THEN** 所选项成为 composer 中的引用胶囊，弹层关闭，焦点回到输入框

### Requirement: 真实入口与法务链接
首页 MUST 复用真实「开始使用」入口（`/start-chat`）与登录流程，保留隐私政策与服务条款链接，且不得出现 GitHub 仓库链接、模拟报名/候补表单或开发者向实现提示。

#### Scenario: 访客点击开始使用
- **WHEN** 访客点击导航、Hero 或底部 CTA 的「开始使用」
- **THEN** 跳转到项目真实的开始使用路由

### Requirement: 响应式与样式隔离
桌面端演示 MUST 支持三列可读布局；移动端不得产生整页横向溢出（三列横向滚动限制在演示容器内）。演示样式 MUST 收敛在独立作用域，不污染 `/thread-chat` 的 `.tc` 样式。

#### Scenario: 移动端访客浏览首页
- **WHEN** 访客以 ≤420px 宽视口打开首页
- **THEN** `document.documentElement.scrollWidth` 不超过视口宽度，导航、场景标签、章节条、FAQ 与 CTA 均可达
