## Why
现有首页以长篇说明为主，不能直接展示已确认的分栏追问体验。用户要求把已发布的第 3 版 Demo 移植为正式首页，并移除 GitHub 入口。

## What Changes
- 移植五类场景、六套剧本、三列追问、章节播放、收起展开和主动引用演示。
- 保留第 3 版标题、副标题、四项价值说明和九个问答。
- 以现有开始使用路由替换模拟报名表单，保留法律页面链接。
- 首页样式和弹层局部隔离，复用正式项目 Base UI；删除旧首页组件。
- 不改变仓库可见性、许可证、数据库或真实聊天逻辑。

## Impact
影响根路由和 components/landing；不增加依赖、数据库或网络服务。
