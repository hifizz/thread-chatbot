# workspace-drawers Specification

## Purpose

为 ThreadChat 工作区提供可共存的侧锚定抽屉基础设施：统一的打开顺序层叠栈、Esc 分层关闭、键盘可达的焦点管理、左右侧形态与可调宽度，供 Project、Artifacts 及后续工作区面板共用。

## ADDED Requirements

### Requirement: 抽屉共存与打开顺序层叠

系统 SHALL 允许 Project Drawer 与 Artifacts Drawer 同时处于打开状态。多个抽屉的 z-index 由打开先后顺序决定，后打开者位于上层。用户点击某个已打开但被遮盖的抽屉、或其顶栏触发按钮时，该抽屉 MUST 被提升至栈顶。同侧重叠时，被遮盖的下层抽屉 MUST 不可交互（inert）。

#### Scenario: 后开的抽屉在上层

- **WHEN** Project Drawer 已打开，用户再打开 Artifacts Drawer
- **THEN** Artifacts Drawer 覆盖在 Project Drawer 之上，两个抽屉均保持其内部状态

#### Scenario: 提升下层抽屉

- **WHEN** 两个抽屉同侧重叠，用户点击下层抽屉可见区域或其顶栏按钮
- **THEN** 下层抽屉提升至栈顶并可交互，另一抽屉转为下层

#### Scenario: 关闭动画期间层级不跌落

- **WHEN** 顶层抽屉开始播放关闭动画，另一抽屉仍处于打开状态
- **THEN** 正在关闭的抽屉保持原 z-index 直至退场结束，不出现先坠落到下层再消失的视觉跳变

#### Scenario: 顶栏触发器始终可达

- **WHEN** 任一抽屉处于打开状态
- **THEN** 顶栏的 Project 与 Artifacts 按钮仍可点击，不被任何抽屉遮挡

### Requirement: 窄屏单抽屉降级

当视口宽度小于 960px 时，系统 SHALL 降级为单抽屉模式：一次只允许一个抽屉可见，另一个保留内部状态但隐藏且不可交互；可见抽屉以接近全屏宽度呈现，且该模式下 MUST 禁用拖拽调宽。视口宽度大于或等于 960px 时 MUST 保持常规抽屉宽度行为，不得过早切换为接近全屏宽度。

#### Scenario: 窄屏打开第二个抽屉

- **WHEN** 窄屏视口下 Artifacts Drawer 可见，用户打开 Project Drawer
- **THEN** Project Drawer 替换 Artifacts Drawer 呈现，Artifacts Drawer 的滚动位置与选中状态被保留

#### Scenario: 窄屏禁用拖拽

- **WHEN** 视口处于窄屏模式
- **THEN** 抽屉不显示拖拽把手，或拖拽把手不产生调宽行为

#### Scenario: 常规宽度边界

- **WHEN** 视口宽度为 960px 或更大
- **THEN** 抽屉保持常规宽度与拖拽能力，不切换为接近全屏宽度

### Requirement: Esc 分层关闭

Esc 按一次只关闭一层，优先级自内向外为：（1）抽屉或弹层内部的瞬态状态（如搜索输入、详情视图、编辑草稿态）；（2）瞬态弹层（帮助面板、会话树、会话列表、划选气泡）；（3）抽屉层叠栈的栈顶。帮助面板、会话树与会话列表之间 MUST 互斥（打开一个即关闭其他）。输入法组合中（isComposing）与按键重复（repeat）产生的 Esc MUST 被忽略。

#### Scenario: 抽屉内态先于抽屉关闭

- **WHEN** Artifacts Drawer 处于详情视图，用户按下 Esc
- **THEN** 先返回列表视图，抽屉保持打开；再次按下 Esc 才关闭抽屉

#### Scenario: 瞬态弹层先于抽屉关闭

- **WHEN** 抽屉打开且会话列表弹层打开，用户按下 Esc
- **THEN** 会话列表关闭，抽屉保持打开

#### Scenario: 弹层互斥

- **WHEN** 帮助面板已打开，用户触发会话树弹层
- **THEN** 帮助面板关闭，会话树弹层打开

#### Scenario: 输入法组合中的 Esc 被忽略

- **WHEN** 用户正在中文输入法组合会话中，按下 Esc
- **THEN** 不触发任何弹层或抽屉的关闭

### Requirement: 焦点捕获与归还

抽屉打开时系统 SHALL 记录触发元素并将焦点移入抽屉。抽屉关闭时 SHALL 将焦点归还触发元素；触发元素已不存在或不可见时，MUST 依次回落到当前最上层抽屉的关闭按钮、再到顶栏。仅提升已打开抽屉的层级时 MUST NOT 重复抢夺焦点。视觉层级最高但只是被遮盖而未关闭的抽屉 MUST 保持其焦点不可达状态，键盘 Tab MUST NOT 进入被 inert 标记的下层抽屉。

#### Scenario: 正常归还

- **WHEN** 用户从顶栏按钮打开抽屉后关闭它
- **THEN** 焦点归还到该顶栏按钮

#### Scenario: 触发元素已卸载

- **WHEN** 触发元素在抽屉打开期间被卸载，用户关闭抽屉
- **THEN** 焦点回落到剩余最上层抽屉的关闭按钮；若无其他抽屉，则回落到顶栏

#### Scenario: 提升层级不抢焦点

- **WHEN** 用户点击下层抽屉使其提升到栈顶
- **THEN** 焦点停留在用户点击的位置，不被强制移动到抽屉关闭按钮

### Requirement: 可调宽度与持久化

Artifacts 抽屉 SHALL 支持拖拽内缘调整宽度：未设置持久化覆盖值时默认与 Project Drawer 同为 520px，最小 320px，最大不超过视口宽度的三分之二。宽度 MUST 在拖拽结束时才持久化到工作区面板尺寸状态，拖拽过程中不写持久层；持久化写入 MUST 保留工作区状态中其他面板尺寸字段。用户 MUST 能通过双击拖拽把手或键盘操作恢复默认宽度，恢复动作清除持久化覆盖值而非写入固定像素。拖拽把手 MUST 支持键盘（方向键微调）并暴露 separator 语义与当前/最小/最大宽度值。

#### Scenario: 拖拽并持久化

- **WHEN** 用户拖拽把手后释放
- **THEN** 抽屉保持新宽度，刷新页面后宽度保持；工作区其他面板尺寸不受影响

#### Scenario: 恢复默认宽度

- **WHEN** 用户双击拖拽把手
- **THEN** 抽屉回到与 Project Drawer 相同的 520px 默认宽度，持久化的宽度覆盖被清除

#### Scenario: 键盘调宽

- **WHEN** 拖拽把手获得焦点，用户按方向键
- **THEN** 抽屉宽度按步进调整，宽限仍受最小/最大值约束

### Requirement: 左右侧形态

抽屉 SHALL 支持左侧与右侧两种锚定形态。右侧形态的进场动画、边框、阴影与把手位置 MUST 在左侧形态下镜像。任一时刻单个抽屉实例只呈现一种形态，形态在打开时确定、关闭前不改变。

#### Scenario: 左侧形态渲染

- **WHEN** Artifacts Drawer 以左侧形态打开
- **THEN** 抽屉锚定在视口左缘，自左侧滑入，拖拽把手位于抽屉右缘

#### Scenario: 视口缩放不翻边

- **WHEN** 抽屉已打开期间用户调整窗口大小
- **THEN** 抽屉保持其打开时的侧向，仅宽度按约束重算；仅在进入窄屏模式时切换为全宽呈现，退出窄屏后恢复原侧向
