# User Taste

## Workflow
- 使用 OpenSpec 时要求严格分阶段推进：先完成并确认 `spec.md` 和 `design.md`，经用户明确同意后才编写 `tasks.md`。Confidence: 0.95
- 使用 Research/调研流程时偏好按 Phase A/B/C/D 分阶段推进，并在每个阶段结束等待用户确认后再继续。Confidence: 0.9
- 要求 Design 文档（OpenSpec design.md）优先定义数据契约与类型——尤其是新实体的数据库 schema（如 quote 的 DB schema）以及输入框/表单配套类型——再展开其他设计内容。Confidence: 0.9

## Communication
- 偏好用中文交流，并直接推进到下一步操作。Confidence: 0.85
